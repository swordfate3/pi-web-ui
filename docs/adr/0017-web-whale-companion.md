# ADR 0017: 浏览器内鲸鱼娘与只读会话用量

## 决策

在现有 React 应用中添加独立悬浮组件，不新建原生项目。显示偏好由 App 持有；位置和本地素材仅属于浏览器。组件通过 Zustand 的 `getUsageStats` 意图请求服务端权威汇总，不从分页消息重算完整会话用量。沿用 `latestCtx` 和 session/runtime 身份校验。

新增纯后端汇总 helper，无网络、无模型查询、不调用收费 API。请求结果只包含计数、实际模型标识、已知费用小计、未定价次数。模型分组有界，合计不依赖当前模型配置。Web 解析器拒绝非法、非有限、负数、过长模型标识和越界行数，旧服务器不支持方法时显示不可用而不是猜测为零。

## 素材分离

本地下载包含多个同人来源，软件仓库的 MIT 声明不能证明整套图片都有相同许可。本次不把图片放入 `public/`、`dist/` 或 npm 包，也不添加外部图片请求。用户通过设置选择本地 PNG/WebP/GIF；校验后保存原始浏览器 Blob，组件只使用 object URL。GIF87a/GIF89a 须通过 magic、MIME 一致性、2 MiB 大小、2048 像素逻辑画布和实际解码尺寸检查；不转换或上传原动画。保留源码和资源许可的边界，今后若获得明确再分发许可，可另行评估带署名的资源包。

## 生命周期和性能

仅展开卡片时请求统计；状态变化和受控定时器触发刷新，禁止重叠请求。会话/运行时/连接变化使旧结果失效；迟到响应不得覆盖新 scope。隐藏、浮层遮盖、组件卸载均停止相关工作。图片 object URL 必须在换图/卸载时释放。CSS 动效是有限次数 transform，不循环 React 渲染或调用模型。用户 GIF 由浏览器原生 `<img>` 播放，不另加 JS 播帧器／canvas 动画循环。为落实用户及系统减少动画偏好，校验时通过 ImageBitmap 首帧生成长边不超过 512 的静态 PNG；设置缩略图始终使用静态预览，宠物在任一减少动画开关启用时使用该预览，两者都不改变 IndexedDB 原图。解码／静态编码设截止时间，迟到 bitmap 关闭，失败不能卡住后续导入队列。原图及静态预览两套 object URL 均按生命周期释放，静态预览不重复持久化。

## 验证

纯 helper/解析器测试与真实 Pi 的 WS/浏览器场景分层；视觉检查另用独立 Browser 桌面和手机截图并直接查看。构建更新 tracked dist 与 manifest，不新增生产依赖。未获本轮额外授权不提交、推送、更新启用包或重载生产。
