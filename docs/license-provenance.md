Integration preserves that initialization commit in Git history, replaces the working-tree license with MIT, and retains upstream attribution. The npm package name remains `@kkkiio/pi-web-ui` for compatibility with the current development snapshot. No npm publish is performed by this GitHub publication. Installing the upstream npm package is not equivalent to installing this fork from GitHub.

## User-imported companion artwork

The Web companion does not bundle the downloaded DeepSeek/whale fan artwork, nor claim that it is covered by this repository's MIT license. Artwork can be selected locally in Settings and stored as browser-local PNG/WebP/GIF Blobs, without uploading it to Pi or fetching an external image host. Original authors and individual artwork licenses remain applicable. The source repository's software license alone is not proof of rights in every character design or collected image; public redistribution requires a separate provenance review. No third-party artwork or extracted upstream application code is included by this feature.
