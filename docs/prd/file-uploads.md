# 工作区附件上传

## 用户目标

在手机／桌面网页选择图片、PDF、文本或其他普通文件，保存到当前 Pi 的本地工作区，再把路径发送给 Pi。项目和附件留在运行 Pi 的机器；阿里云网关／Hub 只转发流量。上传成功不表示模型已经读懂文件，不自动执行、解压或解析文件。

## 交互

- 输入框支持文件选择、拖入和粘贴图片；保留原始字节，不把文件转 Base64 塞进聊天消息。
- 每文件最多 **50 MiB（52,428,800 字节）**，最多选择五个附件。选择时只展示附件，不立即写磁盘。
- 点击发送后，先逐个上传并展示进度；全部成功才发一条 Pi 消息。仅附件也可提交。
- 可取消上传，失败或取消保留草稿及附件，便于重试。成功的文件已经落盘，不因取消另一文件、移除附件或关闭页面而被删除。
- 已上传文件可用于当前页面重试发送，收据短时有效；过期需重新选择／上传，不自动重放消息。明确的交接前拒绝可重试；Pi API 返回不代表已接收，服务端最多等待 8 秒确认当前会话的用户消息。交接后结果不明时明确报错并锁住收据，先检查会话或手动引用已保存文件，不允许用同一收据盲目重发。
- 正在运行模型时附件提交提示等待；不将附件意图放入可能跨会话的文本队列。
- 发生会话切换、扩展重载或路由交接时取消尚在上传的操作并隔离旧收据，不自动向新会话重发旧附件。已经 dispatch 给 Pi 的异步提示无法通过上传取消撤回；尤其第三方异步 hook 与 reload 的交错不在已验证范围，发送结果未知时先检查会话。
- 图片以文件路径提供给 Pi，Pi 可按需使用读取工具查看；其他格式能否解析取决于工具和模型。旧版大 Base64 图片直传不作为新 UI 的发送路径。

## 保存位置

```text
<当前工作区>/
  .pi-uploads/
    <会话 ID>/
      <随机上传 ID>/
        原文件名.pdf
```

原文件名支持中文。服务端生成完整保存路径；浏览器不能任意指定目录。每个文件独立随机目录，重名不会覆盖。文件为私有普通文件，不跟随符号链接。保存到容器工作区仅在该工作区具有持久化挂载时跨容器重建保留。

持久附件不自动清理，也不自动加入 `.gitignore`，避免悄悄改变项目版本控制策略。用户负责按项目需要忽略、备份和清理 `.pi-uploads/`；删除会使旧对话中的附件引用失效。

## 协议边界

1. `prepare_upload({filename,size,sessionId,runtimeId})` 经现有 WebSocket 验证当前会话／运行期，返回短期单次上传授权与相对路径。
2. 浏览器对授权地址执行同源 HTTP `PUT` 原始二进制；Hub 原有 `/s/<generation>/` 代理转发流。文件体不走 16 MiB WebSocket 消息通道。
3. 服务端核验声明大小／实际接收大小，流式写临时文件，成功后公布原文件；失败清理部分文件。
4. 浏览器发送 `prompt({message,uploads:[uploadId],sessionId,runtimeId})`。后端只接受当前 scope 已完成且未交接的收据，并追加服务器生成的文件路径给 Pi，不信任浏览器传入的路径。附件只允许 idle 发送，compaction、忙碌、无模型或无法解析凭据时预检拒绝。
5. 收据在 preflight 前原子预留，防止多网页重复交接；只有匹配当前 scope、完整用户文本及唯一附件路径的 Pi `message_start` 才消费并确认。8 秒未确认表示状态未知，不等于 Pi 拒绝，也不表示后续生成成功。迟到的匹配仍可结算，但服务端不会自动重发。

## 访问与资源保护

- 保留现有 Hub 登记 proof、会话 generation、Origin/Fetch Metadata 与同源边界；Hub 没有自己的网页登录，仍需可信 HTTPS 登录网关。
- 路径遍历、绝对路径、符号链接父目录／目标、隐藏文件名、控制字符和平台保留名称拒绝；不扫描内容，也不能识别所有机密或恶意文件。
- 单次授权、大小、时效、并发、待处理收据数量受限。断开、超限、会话失效与停止服务不能留下未完成文件。
- 不保证抵御同 OS UID／工作区管理员并发更换目录，不承诺扫描病毒、检测所有敏感内容或无限磁盘配额。不要向不可信用户开放 Pi 控制界面。
- 当前 Hub HTTP 代理保持 30 秒上游 socket 空闲超时和 Node 的完整请求时限（默认约 5 分钟）；上传授权也有 10 分钟期限。50 MiB 是文件大小上限，不承诺任意慢网络都能完成，未实现断点续传。无 Content-Length 的 chunked 上传拒绝；标准浏览器发送 File 时由浏览器设置长度，代理须保留它。
- 现有下载端点默认拒绝隐藏目录，因此 `.pi-uploads/` 下的文件不会仅凭聊天路径变成可下载文件；上传与下载权限不互相放开。

## 验证要求

后端纯测试覆盖字节完整性、大小边界、0 字节、超限、断开、路径／符号链接、收据和生命周期。真实 Pi 直连与预构建 Hub 集成验证上传和路径消息；浏览器验证中文文件、原始图片、17 MiB 二进制、多附件、取消／失败、进度及真实工具读取。桌面与手机截图人工检查，独立于功能 E2E。完整安装后的回归必须覆盖新增后端源文件的分发清单。
