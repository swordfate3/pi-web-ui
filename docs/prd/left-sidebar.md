# PRD: Left Sidebar

## Goal

聊天是默认主界面。会话树是按需导航工具，不应在打开网页时永久占用一列。

## Layout

- 桌面与手机初始都关闭侧边栏，不保留图标窄列。
- 顶栏始终提供 `Toggle left sidebar` 入口。
- 桌面打开后，侧边栏展示应用标识、当前会话树、搜索、刷新及底部设置入口。
- 手机打开时使用 Sheet，不把主聊天列挤窄。
- 侧边栏展开时保留内部关闭入口；设置也可从顶栏直接打开。
- 桌面展开状态可拖动 rail 调整宽度；宽度偏好持久化。展开状态是临时 UI 状态，页面刷新后默认关闭。

## Navigation

会话树展示当前 Pi 会话的 entry/branch 结构，不是多项目会话目录。

- 点击节点在聊天中定位相关内容。
- Branch/Continue 保留当前实现的 Pi 生命周期及 `/webui` 权限保护。
- `/tree` 在桌面打开侧边栏，在手机打开对应的 Sheet。
- 关闭或打开侧边栏不切换 Pi 会话，不清空草稿或排队消息。
- `/resume` 的已保存会话选择器独立于这份会话树。

## Long-tree interaction

- 固定行高虚拟列表只挂载视口附近的节点，完整树及 labels 仍参与搜索和导航；DOM 行数不代表历史被截断。
- 搜索后提供“滚动到下一个匹配节点”，按模型索引定位并挂载目标，循环遍历匹配。
- “定位当前节点”清除搜索并展开当前路径，再滚动到对应行。
- 关闭侧栏仅卸载行视图，同一页面内保留搜索、折叠与滚动状态以及当前树缓存。新树会清理失效的折叠 ID。
- 支持上下键/Home/End移动行焦点及左右键展开/折叠；行内操作按钮不误触发行选择。

## Accessibility

- 顶栏 toggle 在桌面和手机均可见，有明确 accessible name。
- Sheet 支持 Escape 和关闭按钮。
- 搜索、设置及刷新入口在展开后可达。
- 已选节点、当前 leaf、loading、search match 保留不同状态。

## Acceptance Criteria

1. 初始关闭且桌面不占用聊天宽度。
2. 顶栏入口可以展开、关闭并再次展开。
3. 手机可触摸打开侧边栏；`/tree` 打开实际 mobile Sheet。
4. 展开后搜索、节点定位与设置入口正常。
5. 完整长会话树及分支保留，不因简约布局截断历史。
6. 桌面宽度调整及原有导航保护仍有效。

## Out of Scope

- 多项目启动与多会话常驻列表。
- 改变 Pi 会话替换、草稿确认或 WebSocket 协议。
- 将默认隐藏等同于删除导航能力。
