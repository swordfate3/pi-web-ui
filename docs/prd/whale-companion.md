# 网页鲸鱼娘

## 范围

在现有 Pi Web 页面内提供轻量悬浮角色，不是系统桌宠，不依赖 Electron、Live2D、视频、新服务或模型调用。只使用结构化连接、工具和 Agent 状态，不读取提示词生成台词。

- 显示立绘、收起为小入口、关闭；关闭后从「设置 → 鲸鱼娘」恢复。偏好和位置仅保存于本浏览器。
- 鼠标/触屏拖动专用把手，方向键移动；点击角色有短暂反馈并打开会话用量卡。
- 待机、思考、工具工作、结束反馈、点击反馈最多五张图；缺少其他图时回退到待机图。无图时显示鲸鱼表情和导入提示。
- 支持桌面和手机可见视口边界、窄屏滚动卡、减少动态效果；设置/模型等浮层开启时暂时隐藏，不盖在对话框上。
- 关闭用量卡后不在后台轮询统计；打开时按受控频率更新。切换会话、运行时、断线时不继续展示旧统计。

## 素材

下载目录里的同人图片不随 MIT 软件公开分发，也不把本机绝对路径当作 Web URL。设置中提供五个本地文件槽，仅接受经签名、解码、尺寸和大小检查的 PNG/WebP。图片在浏览器本地 IndexedDB 保存，渲染使用 Blob URL；不发给 Pi、模型或远程图片站点。只导入待机图也可使用。

已下载桌宠目录的建议对应关系：

| 槽 | 文件名 |
| --- | --- |
| 待机 | `dsh-whale-state-idle-cute.webp` |
| 思考 | `dsh-whale-state-thinking.webp` |
| 工具 | `dsh-whale-state-tool.webp` |
| 完成 | `dsh-whale-state-success.webp` |
| 点击 | `dsh-whale-state-react-head.webp` |

这是每个浏览器/站点的数据，不是 Pi 工作区数据，不随会话同步。不同 Hub 会话路径在同一站点可能共用素材与显示偏好。浏览器清站点数据会清除图片；受限环境无法持久化时须提示。用户负责遵守各图片原始许可；本地导入不赋予再分发权。

## 用量与费用

`get_usage_stats({sessionId,runtimeId})` 返回当前会话全部条目（包括分支），不是当前日期分页、当前分支或今日跨会话账本。不包含正文、会话文件路径、凭据或其他会话数据。

- 使用 Pi 已记录的实际 usage 和 cost。按 Provider 与 `responseModel ?? model` 分组，不用当前选中的模型给旧请求套单价。
- 输入、输出、缓存读取、缓存写入分列；reasoning 属于输出、cacheWrite1h 属于缓存写入，不重复加。
- 缺失/无效价格、带用量但只有零价的记录保守标记未定价。部分已知显示「已知小计 + 未定价次数」，不能显示成全部免费。
- 显示 USD 与「Pi 估算」，不承诺等于代理渠道折扣、币种转换或实际账单。
- 模型行数有界；超额进入其他模型汇总，总量不能悄悄遗漏。摘要/工具的无法归属用量单独分组，不猜成最近选择的模型。
- 最近响应来自完整会话统计，不由日期过滤后的聊天列表估算。

## 非目标

不做账户余额、账单 API、跨设备同步、今日跨会话数据库、提示词分析、自动闲聊、跨软件置顶或常驻高帧率动画。素材导入与角色点击不消耗模型 Token。
