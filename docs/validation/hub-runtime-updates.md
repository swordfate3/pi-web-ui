# Hub 全局 Pi 更新：本地验证

日期：2026-10-18。基线 `origin/main` 为 `69aa826`（1.0.0），开发分支
`codex/hub-runtime-updates`。不表示已发布、部署或更新生产Pi。

## 实现和边界

- 独立管理入口增加精确版本申请、策略、任务及逐目标进度。可选`runtimeUpdates`
  使用Gate普通申请凭据，与单进程重启的生命周期凭据分离；聊天origin没有管理接口。
  延用一次性配对、私有cookie、CSRF、来源和撤销检查。
- 只调用固定loopback runtime路由，没有批准、改策略、解除恢复阻塞、Docker或shell能力。
  Gate负责审计、策略、安装和安全空闲刷新；旧容器仍需迁移。
- 提交前保存公开任务ID和版本。未知结果仅同ID查询，不自动重复POST。
- Gate目标历史跨退出和更替累计，允许129条以上；每次响应限5秒／16 MiB，最多100项历史。
  页面每任务显示128条目标记录、优先非退出目标并提示总数，不修改Gate记录和完成判断。
- 授权代际隔离旧200／401及JSON晚到响应；新轮询不被旧轮询锁阻塞。
  配对与锁定请求串行，避免旧logout的晚到Set-Cookie擦除新cookie。
  未知POST即使中途重新解锁仍保留原任务ID；完成目标不再显示残留的旧忙碌原因。

## 验证

- 新runtime API回归15/15：实际临时Hub与模拟Gate HTTP边界，包含权限、响应投影、
  精确身份、异常输入、Gate拒绝、丢失回包、Hub重启、撤销、满历史与目标更替。
- 页面行为17/17：实际管理脚本的VM/DOM执行，包括未知结果不重发、恢复阻塞、
  存储失败拒绝POST、旧200／401、提交中重新配对和带cookie模型的晚到logout。
- 原单进程重启页面回归3/3；完整`npm run test:unit`共480项，479通过、
  1项可选大流测试跳过，无失败或取消。
- 两套类型检查、`npm run build:web`、`npm run verify:dist`和`git diff --check`通过。
  Biome无error，保留基线30 warnings／1 info；Vite保留大chunk提示。
- 新功能与审查修复先观察新增回归失败，再实现后通过。独立审查指出的历史预算、
  累计目标上限和授权转换竞态均补回归，不靠放宽权限绕过。
- 最后针对两轮授权竞态修复的独立只读复审无剩余可操作问题；复审者另行确认
  页面17项、连接类型和空白检查通过，但未重复本报告的完整套件或浏览器检查。
- 首轮完整回归发现基线版本检查测试的`unref`计时器与无socket挂起源会让工作进程提前退出。
  只给该测试增加有清理的保活句柄，产品逻辑、超时和断言不变。
- 另一次完整回归中，模拟Gate的异步HTTP回调对未认证请求直接断言抛异常，造成未处理拒绝。
  改为与真实Gate一致的401拒绝后，独立接口15项和最终完整480项均正常退出；
  正向接口断言仍要求200／202，未放宽产品认证或测试预期。

## 上线前提

没有推送、更新本机安装包、提交生产任务、批准策略、安装Pi、迁移旧容器、修改阿里云
或重启生产服务。上线需部署新Hub并只读接入正确申请凭据；只更新会话内扩展不等于Hub更新。
Gate仍限制已审计版本和可信镜像，忙碌Pi延后刷新，旧容器不能由此绕过兼容检查。
未知、恢复阻塞或超预算不应被当作任务取消后盲目重提。使用说明见[Hub文档](../hub.md)。
